# CodeTrappers Trending Topics Dashboard

A dashboard to discover, review, shortlist, and finalize trending topics for the CodeTrappers blog.

## Categories
- Artificial Intelligence
- Web Development
- App Development

## Features
- Discover trending topics
- Search and filter topics
- Shortlist or reject topics
- Finalize one topic
- View original source links

## Tech Stack
- React
- Vite
- Supabase
